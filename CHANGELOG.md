# Changelog

## 0.1.0 — 2026-11-12

- Extracted the software CRT renderer into an independent Python package.
- Added configurable curvature, scanlines, phosphor texture, edge shading, and bloom.
- Added aspect-preserving presentation, a curved bezel, and mouse coordinate helpers.
- Added a procedural interactive demo, minimal integration example, and English README.
- Added backend compatibility tests and packaging/CI checks.
